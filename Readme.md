
# 🏭 Connected Factory Solution

## 📌 Project Overview

The **Connected Factory Solution** is a networking project developed using Cisco Packet Tracer. It demonstrates how networking technologies can be used to connect different devices and systems in a manufacturing environment.

The project focuses on building a connected industrial network that enables communication between devices and supports efficient data exchange within a factory.

## 🎯 Objectives

- Design a connected network for a manufacturing factory.
- Understand industrial networking concepts.
- Establish communication between network devices.
- Configure and manage network connectivity.
- Explore how networking supports smart manufacturing environments.

## 🛠️ Tools & Technologies

- **Cisco Packet Tracer**
- Computer Networking
- Network Topology Design
- IP Addressing
- Network Configuration

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Install Cisco Packet Tracer.
3. Open the `.pka` file using Cisco Packet Tracer.
4. Explore the network topology.
5. Run simulations and test network connectivity.

## 📚 Learning Outcomes

- Practical understanding of computer networks.
- Experience with Cisco Packet Tracer.
- Understanding of industrial network connectivity.
- Hands-on experience with network simulation and troubleshooting.
